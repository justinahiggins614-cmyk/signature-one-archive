Catalog data files

Every data file behind the Signature Spec Catalog, as static crawlable links. Shard indexes are gzipped JSON arrays; each spec row carries its permanent JAH-SPEC-###### identifier. Per-record deep links follow the pattern specs.html?spec=JAH-SPEC-000123. All records are draft invention specifications authored by Justin Addam Higgins (JAH) — drafts, ready to review and file; not granted patents; not affiliated with the USPTO.
