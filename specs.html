What is a spec?

A spec (specification) is a written description of an invention: what it is, what it does, how it would be built, and how it would work. Every entry in this catalog is a draft patent specification — the paperwork you would prepare before filing a patent. These are drafts, not granted patents: ideas fully described on paper, authored by Justin Addam Higgins (JAH), ready to review and file.

How to use these specs

Each entry is a draft invention specification by Justin Addam Higgins (JAH), written in the forced Signature-One format: title, abstract, six-tool signature mapping, key parameters, a machine-readable autoread block, and the five reversed-allowance algorithm steps. Search the catalog

Type in the search box and press Search (or Enter) — results also filter as you type. You can search by title, keyword, spec ID (JAH-SPEC-######), inventor (Justin Addam Higgins), or category.

Narrow it down

Category pills filter to one field of invention. Sort orders A–Z, newest first, or oldest first. Era picks Past, Current, or Future inventions (the invention’s time context as classified when the spec was generated — descriptive only). Filters combine with search.

Jump around

A–Z letter buttons jump to titles starting with that letter. Shard jump jumps straight to an ID range of the archive. Show more loads 100 more results at a time.

Open a spec

Every card is one draft spec: its permanent ID, title, abstract, category, and era. Show abstract toggles the abstract. Spec details opens the full record with seven lenses: Official Standard, Patent filing, Overview, Manufacture, AI explains, Code, and Demo.

Read the record honestly

Each record opens with a DRAFT — NOT A GRANTED PATENT banner and a validation block that says plainly what was actually tested. SIGNATURE-1 VALID means the record passes Signature-One schema/data validation — a data status, not physical, prototype, or manufacturing validation. Strong wording like “factory-ready” describes the design as specified — the inventor’s theory, not measured results.

AI explainer

The AI explains lens gives a plain-English what-it-is and how-it-works, plus a personal AI you can ask anything about the product — it answers only from that spec’s own record and says so when the record doesn’t cover a question. Quick Spec Helper chips answer “What is it?” and “How does it work?” in one tap.

Read aloud
